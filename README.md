# Site institucional Plena-Lab

Versão existente aprovada, desenvolvida em HTML, CSS e JavaScript.

## Desenvolvimento local

Na pasta dist, execute `python -m http.server 4174 --bind 127.0.0.1` e abra http://127.0.0.1:4174/.

Não há instalação de dependências nem compilação. O formulário, catálogo e acesso de revendedores são demonstrativos. Não há backend nem banco de dados.

## Histórico e publicação

Registrar alterações em commits e no CHANGELOG.md. O envio de commits ao GitHub guarda o histórico; não autoriza publicar o site. Não configurar implantação automática ou GitHub Pages sem autorização expressa.

Documentos comerciais, contratos e credenciais devem permanecer fora deste repositório.
